# Transfer Case Schema

Use this schema for every empirical transfer case.

## Case identity
- Case ID
- Source environment
- Target environment
- Policy/mechanism
- Time period
- Outcome

## Source structure
- Formal policy representation
- Claimed causal mechanism
- Supporting evidence
- Assumptions
- Necessary structures
- Enabling structures
- Incidental features

## Target structure
- Formal policy
- Relevant structures present
- Structural differences
- Evidence for the mechanism
- Alternative explanations

## Assessment
Choose only after evidence review:
- Supported transfer
- Conditional/partial transfer
- Structural mismatch
- Transfer failure
- Insufficient evidence

The assessment must be accompanied by evidence and reasoning.

## Audit trail
- Sources
- Data
- Methods
- Analysis
- Competing explanations
- Unresolved issues
- Next test
